# Technical Spec

Beschrijf de technische stack, frameworks, versies, architectuurafspraken,
codeconventies en bekende valkuilen.

Documenteer hier ook de commands uit `.factory/verification.yaml`. Na een muterende developer- of
documenterjob voert Agent Runtime deze zelf uit en levert afzonderlijk, revisiongebonden
verificatiebewijs. De factory valideert status, branch en commit onafhankelijk en fail-closed; een
rode of onvolledige verificatie wordt niet gepubliceerd.
