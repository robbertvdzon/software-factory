# Functional Spec

Beschrijf wat de applicatie functioneel moet doen, welke gebruikersflows
belangrijk zijn, en welke acceptatiecriteria vaak terugkomen.

Testers onderscheiden aangetoonde fouten, herstelbare testvoorwaarden en structurele
beperkingen. Voldoende alternatief bewijs kan leiden tot `tested-with-limitations`.
Een structurele beperking vraagt direct een menselijke beslissing; na de derde afwijzing
stopt de automatische herhaling. De onafhankelijke repositoryverificatie blijft gelden.
